02 EXPERIMENTS

埋め込みの取り方

inspect_input→embed

見えるトークンを変える

入力を展開した後のトークン位置を確認し、層とクエリヘッドを選んでアテンションの辺を開閉します。メディアは先に register_media で登録します。

embed_batch/submit_embedding_job

複数の入力をまとめる

同期バッチは入力順に結果を返します。大きなジョブは結果を順次保存し、サーバーの再起動後も未完了の項目から処理します。

03 CONNECTION

MCP に接続する

Gemini のカスタムアプリ、または Streamable HTTP 対応の MCP クライアントに URL を登録します。

MCP への接続には送信元 IP の許可リストが適用されます。
